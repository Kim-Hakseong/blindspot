# Datasets

Provenance and licence for every image Blindspot is evaluated on. Nothing is
used whose licence does not permit it, and nothing is redistributed that its
licence does not permit redistributing.

## Status

| Set | Purpose | Licence | Status |
|---|---|---|---|
| Synthetic reference scene | Unit tests and degradation response benchmark | Generated by this repo, MIT | In use |
| `val/road100` | Road scene validation set (100 frames, 984 objects) | COCO val2017 images: CC BY 2.0 (72) / CC BY-SA 2.0 (28); annotations CC BY 4.0 | In use — `val/road100/manifest.json` |
| `val/indoor100` | Indoor/safety validation set (100 frames) | To be selected | Not yet acquired |
| `val/retail100` | Retail shelf validation set (100 frames) | To be selected | Not yet acquired |
| Real-capture set | sim-to-real gap measurement (30–50 frames) | Original capture, MIT | Not yet captured |

The synthetic reference scene is generated deterministically by
`bench/degrade_response.py` from a fixed seed. It contains no photographic
content and therefore no licensing or privacy question. It exists so the
degradation kernels can be verified without a data dependency; it is **not**
used to make any claim about detector accuracy.

## Published frames

Four evidence frames in `bench/out/frames/` are rendered from `road100` and are
therefore redistributed pixels. They are restricted to **CC BY 2.0** sources
(never the share-alike subset), each is credited with its original Flickr URL
and licence in `bench/out/frames/frames.json`, and each is modified as stated
there (overlay drawn, faces blurred, degradation applied on the right half).

Faces are blurred automatically with YuNet (`cv2.FaceDetectorYN`, OpenCV model
zoo) at render time only — scoring always runs on the untouched frame, so
anonymisation cannot move a measured number. Automatic detection can miss
small or side-on faces, so every frame is reviewed by eye before it appears in
the video or on the public report.

## Selection criteria

A validation set is only eligible if all of the following hold:

1. The licence permits research use and permits publishing derived measurements.
2. The licence terms are stated by the publisher, not inferred.
3. Per-image provenance can be recorded, so a failing frame in a report can be
   traced to its source.
4. Redistribution status is explicit. Where redistribution is not permitted,
   this repository commits only image hashes and a fetch script, never pixels.

## Responsible use

- Frames containing identifiable faces are blurred before appearing in any
  demo, report, or video, or are excluded.
- Blindspot reports the behaviour of a *pipeline*, not of the people or
  property in the frames. No output is derived about individuals.
- Every degraded frame in a report is regenerable from `(source image, params,
  seed)`, so reports reference sources rather than embedding redistributed
  copies.

## Recording format

Once acquired, each set records here: source URL, publisher, licence and its
URL, retrieval date, image count, a SHA-256 manifest committed under
`val/<set>/manifest.sha256`, and whether pixels are redistributed or fetched.
